# MarauTech 🔧⚡

> **Electronics meets code** - We create practical RF solutions, custom PCBs, firmware for ESP32/ESP8266, and web-based tools.

## 🚀 About Us

MarauTech is a team of electronics and programming enthusiasts who bridge the world of hardware with software. We specialize in:

- **RF Tools** - tools for analyzing and manipulating radio signals
- **Custom PCBs** - designing custom printed circuit boards
- **Firmware Development** - software for ESP32/ESP8266 microcontrollers
- **Web-based Tools** - modern tools running in the browser
